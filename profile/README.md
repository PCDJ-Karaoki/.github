# PCDJ Karaoki — karaoke host for a venue queue

PCDJ Karaoki keeps one named board on the desk: the live karaoke host, the singer in front of you, and a short note the next rotation can read. Extra queues wait for their own title.

## How PCDJ Karaoki Sits

PCDJ Karaoki does not replace the paper queue, the random track folder, or the consumer karaoke player you already keep. It sits beside them as a named venue desk for one job: which karaoke host is live, which song queue still matches the rotation, and what the next host should read.

If two people share a venue PC, each keeps a PCDJ Karaoki style of their own. Extra queues wait for their own title instead of crowding the live rotation.

A first visit should be one short singer, then the same PCDJ Karaoki venue desk the next night. That is enough to see if the named karaoke host holds.

## Open Order

1. Open the last PCDJ Karaoki venue desk, not a new empty karaoke host.
2. Read the song queue and the last handoff.
3. Finish one visible rotation pass inside PCDJ Karaoki.
4. Write what changed, then close with fewer random tracks than you found.
5. If the queue feels crowded, drop anything that belongs to a different PCDJ Karaoki night.
6. Confirm PCDJ Karaoki karaoke host still holds the rotation you run.
7. Leave the venue desk title on the board before you close.
8. Check PCDJ Karaoki song queue still sits on the same named host.

## After a Week

A week in PCDJ Karaoki is not a larger folder of random tracks. It is the same title, a shorter live song queue, and a note that still makes sense before the next singer. Take finished songs off the live set so the next visit starts on the karaoke host that is still open.

Other programs stay where they are. PCDJ Karaoki only keeps the path back: desk name, karaoke host, rotation, handoff.

Leave PCDJ Karaoki with a quieter venue desk than the one you opened. The next visit should start on that host, not in a random track folder.

## Field Note

PCDJ Karaoki is easier to trust when the venue desk stays smaller than the random track folder it came from. Name the host, keep the live rotation, finish one visible singer, and write what changed.

The same loop fits a second room, a close-out night, or a shared venue PC. Open the last PCDJ Karaoki desk and continue. Do not rebuild the song queue from scratch.
